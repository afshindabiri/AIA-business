# Solution Selection

## Purpose

This file owns the decision ladder for selecting an appropriate solution approach. It does not mandate a technology or own a Client-specific decision.

```text
Remove?
↓
Simplify?
↓
Standardize?
↓
Existing Tool?
↓
Integrate?
↓
Automate?
↓
AI?
↓
Custom Build?
```

This is a decision ladder, not a requirement that every project pass through every technology. Stop at the simplest approach that responsibly solves the validated problem. Apply [[Operating-Principles]] and evaluate actual tools through [[Tool-Selection]].
