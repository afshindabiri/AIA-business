# Discovery

## Purpose

This file owns the lean Discovery method. It does not own the Focused Audit, implementation design, or current pricing.

Capture only decision-relevant information:

- Primary Problem
- Current Process
- Main Bottleneck
- Business Impact
- Evidence
- Relevant Systems
- Access
- Next Step
- Outcome

Discovery is lean. It determines whether a real, focused problem justifies the next step.

Discovery must not become:

- a technical Audit;
- a full data-readiness assessment;
- API interrogation;
- a giant questionnaire;
- a scoring framework.

Discovery may consume approved pre-consultation intake information from [[Consultation-Intake]]. Using that input does not turn Discovery into a questionnaire, and it does not replace the Discovery conversation.

Detailed feasibility belongs in the Focused Audit where needed. Discovery must not promise a solution before evidence is sufficient.

Client records use [[DISCOVERY-PHASE-TEMPLATE]]. The next method, when justified, is [[Paid-Audit]]. Current commercial terms: [[Pricing-Policy]].
