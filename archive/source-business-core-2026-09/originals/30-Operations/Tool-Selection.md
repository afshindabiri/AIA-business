# Tool Selection

## Purpose

This file owns the criteria for choosing tools. It does not maintain a preferred-vendor list or own a Client's final technical architecture.

Use decision-relevant criteria:

- capability fit;
- reliability;
- integration;
- data and privacy;
- cost;
- ownership and exit;
- complexity.

Do not choose a tool merely because AiA already knows or likes it. Chatwoot, n8n, Activepieces, Trigger.dev, LiteLLM, Langfuse, Payload, and any other tool may be selected only when justified by a specific project; none is a default.

Follow [[Solution-Selection]] and keep detailed technical evaluation in the linked technical project workspace.
