# Offer Architecture

## Purpose

This file owns AiA's current commercial offer sequence. It does not own current prices, delivery methodology, or individual Client terms.

```text
Assessment / Conversation
↓
Discovery
↓
Focused Business Automation & AI Audit
↓
Implementation
↓
Optional Post-Implementation Services
```

## Rules

- Assessment is optional.
- Discovery is the initial understanding stage.
- The Focused Audit is the diagnostic product; its current commercial treatment is owned by [[Pricing-Policy]].
- Implementation follows only when justified.
- Post-implementation services are optional.
- AiA does not use Bronze/Silver/Gold packages or artificial tiers.
- An implementation proposal normally contains one recommended path and, when useful, one meaningful alternative.
