# Implementation Offer

## Purpose

This file owns the current structure of implementation work. It does not own current pricing or commercial terms, delivery gates, or a Client's agreed scope.

- Scope is project-specific and based on the validated problem.
- Use clear milestones where practical; current milestone and pricing policy lives in [[Pricing-Policy#Implementation commercial structure|Pricing Policy]].
- Use existing SaaS and tools when they are the best solution.
- Multiple tools may be combined.
- Add a small custom layer where useful.
- Custom software is not automatically preferred; custom-build only when justified.
- Identify third-party dependencies and ownership explicitly.
- A Pilot is optional.
- Production, Stabilization, Acceptance, and Handover are part of delivery.
- Do not create artificial packages.

Current pricing and third-party cost terms: [[Pricing-Policy]]. Delivery method: [[Implementation-Delivery]], [[Pilot]], and [[Acceptance-and-Handover]]. Historical agreed scope belongs in the relevant Client Phase snapshot.
