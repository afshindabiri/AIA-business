# Pipeline Definition

## Purpose

This file owns the meaning and order of current sales pipeline stages. It does not own a Client's live status, pricing, or performance metrics.

| Stage | Definition |
|---|---|
| Target Business | A business selected for relevant outreach based on a plausible operational problem. |
| Relevant Outreach / Content / Referral | A relevant path has created or attempted attention and trust. |
| Automation Opportunity Call | A conversation is used to understand whether a real problem exists. |
| Focused Audit | A focused diagnostic is offered or undertaken when justified. |
| Proposal | Audit findings support an implementation proposal when justified. |
| Implementation | Agreed implementation work is active. |
| Result | The engagement has reached a documented outcome. |
| Proof / Referral | A testimonial, case study, or referral may be requested when earned and permitted. |

The relevant Client/Cycle/Phase record—not this definition—owns live pipeline state. Funnel context: [[Sales-Funnel]]. Current commercial terms: [[Pricing-Policy]].
