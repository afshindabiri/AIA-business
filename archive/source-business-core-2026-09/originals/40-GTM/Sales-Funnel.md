# Sales Funnel

## Purpose

This file owns the current GTM funnel. It does not own current pricing, Client-specific pipeline state, or acquisition performance.

## Core funnel

```text
Relevant Attention
→ Trust
→ Conversation
→ Focused Audit
→ Implementation
→ Result
→ Proof
→ More Trust
```

## Operational funnel

```text
Target Business
→ Relevant Outreach / Content / Referral
→ Automation Opportunity Call
→ if real problem: Focused Audit
→ if implementation justified: Proposal
→ Implementation
→ Result
→ Testimonial / Case Study / Referral
```
