# منابع تاریخی ساخت وب‌سایت

## منابع طراحی و محدودیت استفاده

- [یادداشت مرجع طراحی](../archive/source-website-2026-10-22/design-references/README.md): سابقهٔ رد جهت طراحی اکتبر؛ فهرست مرجع خالی است، نه طرح منتخب یا تأییدشده.
- [قالب خالی ثبت مرجع](../archive/source-website-2026-10-22/design-references/REFERENCE-TEMPLATE-fa.md): برای شناخت فرایند سابق، نه فایل طراحی یا مجوز استفاده از اثر.
- هر ۴۷ رکورد کاتالوگ تاریخی `ingestible=false` دارد و هیچ تأیید عمومی سایت یا چت ثبت نشده است. متن قدیمی، قیمت‌گذاری، پشتیبانی، فرم نه‌فیلدی و گروه‌بندی خدمات باید با تصمیم‌های نوامبر تطبیق داده شوند.
- ناسازگاری تاریخی FAQ08 (پرسش دربارهٔ نظارت انسانی، پاسخ مربوط به پشتیبانی) عمداً در اصل حفظ شده؛ آن را FAQ معتبر یا پاسخ آماده تلقی نکنید. دستورهای اجرایی داخل این اسناد مجوز تازه برای اجرا، کدنویسی یا انتشار نیستند.
